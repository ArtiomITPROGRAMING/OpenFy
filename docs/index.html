Как установить тему в OpenFy

1

Установка в 1 клик

Откройте эту страницу на телефоне и нажмите кнопку «В OpenFy» на любой теме. Плеер автоматически откроется и применит тему!

2

Авто-синхронизация аккаунта

Перейдите на этот сайт из плеера (Настройки → Темы → Веб-витрина). Профиль на сайте синхронизируется с телефоном автоматически без паролей.

3

Через файл .thm или .json

Скачайте созданный файл темы `.thm` или `.json`, затем в плеере нажмите «Импорт из файла» либо просто откройте файл в проводнике телефона.

Профиль Автора OpenFy

Привяжите профиль для публикации тем и синхронизации с телефоном

📱 Автоматическая синхронизация:
Откройте плеер OpenFy на телефоне, перейдите в Настройки → Темы → «Веб-витрина (GitHub Pages)». Ваш профиль автоматически передастся на этот сайт без необходимости ввода логинов и паролей!

## 🌟 О проекте

**OpenFy** — это современный музыкальный плеер нового поколения для операционной системы Android, созданный на передовом стеке **Jetpack Compose** и **AndroidX Media3 (ExoPlayer)**.

Приложение разработано по строгой философии **Offline-First**: оно не требует создания аккаунтов, не содержит аналитики, трекеров и рекламы, и не отправляет сетевых запросов при прослушивании вашей личной коллекции треков.

## ✨ Главные возможности

### 🎧 Аудиодвижок высокой чёткости
- **Продвинутый плеер на Media3 / ExoPlayer**: безупречное воспроизведение локальных файлов с нулевой задержкой.
- **Широкая поддержка форматов**: MP3, FLAC, AAC, OGG, WAV, M4A, Opus.
- **Бесшовное воспроизведение (Gapless Playback)** и корректная обработка аудиофокуса при звонках и уведомлениях.
- **Поддержка Android Auto**: полноценная навигация по вашей медиатеке на дисплее автомобиля.

### 🎤 Караоке и Тексты песен (.LRC)
- **Умный автопоиск .LRC файлов**: сканирует папку рядом с аудиофайлом, находя связанные файлы текстов независимо от регистра расширения (`.lrc`, `.txt`) и нюансов названия.
- **Потоковый экстрактор встроенных тегов**: мгновенно считывает тексты, зашитые в метаданные ID3v2 (`USLT`), FLAC (`VORBIS_COMMENT`) и MP4/M4A (`©lyr`), эффективно пропуская тяжелые обложки `APIC` без ограничений по размеру буфера.
- **Мульти-кодировки**: поддержка UTF-8, UTF-16 и автоматический фоллбэк на Windows-1251 (CP1251) для русскоязычных архивов.
- **Интерактивная синхронизация**: плавная автопрокрутка текста в ритм треку и мгновенный переход к нужному фрагменту по нажатию на строку.

### 🎚️ 5-полосный аппаратный DSP Эквалайзер
- **5 частотных полос**: тонкая калибровка диапазона от 60 Гц до 14 кГц.
- **Звуковые эффекты**: Усилитель низких частот (**Bass Boost**), 3D **Виртуализатор** пространства и пресеты **Реверберации** (Small Room, Medium Hall, Large Hall и др.).
- **Сохранение профилей**: мгновенное восстановление сохраненных параметров при старте аудиосессии.

### 🏎️ Автомобильный режим (Car Mode)
- **Безопасность за рулём**: высококонтрастный интерфейс с гигантскими областями нажатия.
- **Лаконичный дизайн**: фирменные векторные иконки Material Icons без отвлекающих визуальных элементов.
- **Быстрые подборки**: запуск избранных треков, дорожного микса и недавней музыки в одно касание.

### 🎨 Премиальный дизайн и эргономика
- **Material You Dynamic Theming**: гармоничное извлечение ключевых цветов палитры прямо из обложки текущего альбома.
- **Глубокая тема Pure OLED**: идеальный черный цвет для экономии энергии на AMOLED-экранах.
- **Плавающая док-капсула**: быстрый доступ к тексту, эквалайзеру, очереди, таймеру сна и авто-режиму.
- **Жесты на обложке**: свайп влево/вправо для переключения треков, двойной тап для паузы/возобновления.
- **Бегущая строка (Marquee)**: длинные названия треков и исполнителей отображаются полностью без усечений.

## 🔒 Приватность и автономность

| Параметр | OpenFy |
|---|---|
| **Подключение к сети для музыки** | ❌ Не требуется (100% Offline) |
| **Реклама и промо-блоки** | ❌ Отсутствуют |
| **Сбор телеметрии и трекеры** | ❌ 0 трекеров (Clean FOSS) |
| **Регистрация / Аккаунты** | ❌ Не нужны |
| **Google Play Services** | ❌ Полностью исключены (F-Droid Ready) |

## 📱 Системные требования

- **Операционная система**: Android 7.0 (Nougat, API 24) и новее.
- **Рекомендуется**: Android 12+ для полной поддержки динамических тем Material You.
- **Архитектуры**: `arm64-v8a`, `armeabi-v7a`, `x86_64`.

## 📦 Установка

### 1. GitHub Releases
Скачайте актуальный готовый APK-файл из раздела [**Releases**](https://github.com/OpenFy/OpenFy/releases) и установите его на устройство.

### 2. F-Droid
OpenFy полностью подготовлен к включению в официальный каталог [**F-Droid**](https://f-droid.org/). Метаданные Fastlane и рецепт сборки расположены в каталогах `fastlane/` и `metadata/`.

---

## 🛠 Сборка из исходников

Для самостоятельной сборки приложения вам понадобятся:
- **JDK 17** (рекомендуется Eclipse Temurin или OpenJDK 17).
- **Android SDK** (API Level 36).

```bash
# 1. Клонируйте репозиторий
git clone https://github.com/OpenFy/OpenFy.git
cd OpenFy

# 2. Сборка Debug APK
./gradlew assembleDebug

# 3. Запуск юнит-тестов и проверки качества кода
./gradlew testDebugUnitTest
./gradlew lintDebug

# 4. Сборка оптимизированного релизного пакета с R8
./gradlew assembleRelease
```

Собранный APK будет доступен по пути:
`app/build/outputs/apk/release/app-release.apk`

## 🏗 Архитектура проекта

Проект организован по современной многомодульной модульной архитектуре Android:

```
OpenFy/
├── app/                  # Основной модуль: экраны Compose, навигация, динамические иконки
├── core/
│   ├── audio/            # ExoPlayer / Media3 сервис, LyricsRepository, EqualizerController, MediaStore
│   └── ui/               # Дизайн-система, темы, компоненты, карточки, векторные иконки
├── features/
│   ├── themes/           # Управление темами, акцентными палитрами и кастомизацией
│   ├── community/        # Локальный P2P-обмен плейлистами по Wi-Fi/QR без интернета
│   └── streamer/         # Предпросмотр локальных аудиопотоков
├── fastlane/metadata/    # Описания и чейнджлоги для каталогов приложений (F-Droid)
└── .github/workflows/    # CI/CD автоматизация сборки и тестирования
```

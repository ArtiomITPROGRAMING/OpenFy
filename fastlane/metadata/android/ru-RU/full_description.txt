OpenFy — современный, быстрый и полностью автономный локальный аудиоплеер для Android, созданный на базе Jetpack Compose и AndroidX Media3 (ExoPlayer). Приложение работает на 100% офлайн, гарантируя абсолютную конфиденциальность без сбора телеметрии, рекламы и привязки к облачным аккаунтам.

✨ Главные особенности:

🎵 Продвинутый офлайн-движок воспроизведения
- Чистый и детальный звук на базе ExoPlayer и Media3.
- Поддержка форматов: MP3, FLAC, AAC, OGG, WAV, M4A, Opus.
- Бесшовное воспроизведение (Gapless Playback) и умное управление аудиофокусом.
- Интеграция с Android Auto для управления музыкой на экране автомобиля.

🎤 Синхронизированный текст караоке (.LRC)
- Автоматический поиск .lrc файлов рядом с треками на диске (регистронезависимый поиск).
- Встроенный потоковый парсер тегов без ограничения буфера (ID3v2 USLT, FLAC VORBIS_COMMENT, MP4 ©lyr).
- Автоматическое распознавание кодировок (UTF-8, UTF-16, Windows-1251).
- Плавная караоке-прокрутка строк с возможностью быстрого перехода по нажатию на строку.

🎚️ 5-полосный аппаратный DSP Эквалайзер
- 5 частотных полос (60Гц, 230Гц, 910Гц, 3.6кГц, 14кГц).
- Усилитель басов (Bass Boost), 3D виртуализатор и пресеты реверберации.
- Сохранение и мгновенное восстановление пользовательских настроек при каждом воспроизведении.

🚗 Режим вождения (Авто)
- Высококонтрастный, эргономичный интерфейс с крупными кнопками.
- Полностью векторные иконки Material Icons без отвлекающих эмодзи.
- Быстрые плейлисты в дорогу: Избранное, Микс, Недавние.

🎨 Dynamic Material Design & Кастомизация
- Автоматическое извлечение динамических акцентов из обложек треков (Material You).
- Глубокая темная тема Pure OLED для экономии заряда батареи.
- Плавающая док-капсула управления в полноэкранном плеере.
- Жесты на обложке: свайп для переключения трека, двойной тап для паузы/возобновления.
- Таймер сна с плавным затуханием громкости.

🔒 Свободное ПО и полная приватность
- Без рекламы, без трекеров и без аналитики.
- Не требует подключения к интернету для воспроизведения вашей музыки.
